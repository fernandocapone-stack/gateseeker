# Fonts

Google Sans Flex, variable (optical size 6..144, weight 300..800), SIL Open Font
License 1.1 (see OFL.txt). Chosen by the PO on 2026-10-28.

Source: the woff2 subsets served by Google Fonts for
`https://fonts.googleapis.com/css2?family=Google+Sans+Flex:opsz,wght@6..144,300..800`
(v26), `latin` and `latin-ext` only. The upstream project is
https://github.com/googlefonts/googlesans-flex; the full TTF in google/fonts
is 3.9 MB, which is why only these two subsets are shipped.

Self-hosted on purpose: the hosted page runs under a CSP that allows only
same-origin stylesheets and fonts, and no request to Google is made.
